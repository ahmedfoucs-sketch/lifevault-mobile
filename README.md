# LifeVault App — الشريحة الرأسية (E2EE)

ما يعمل الآن: إنشاء خزنة مشفرة على الجهاز، مفتاح استعادة، فتح/قفل، إضافة/عرض/حذف عناصر، نسخة احتياطية مشفرة، قفل تلقائي.
التشفير: PBKDF2-SHA256 (600,000) ← HKDF (authKey + kek) ← AES-GCM لتغليف DEK، وAES-GCM لكل عنصر (AAD = معرّف العنصر).
**غير موجود بعد:** المزامنة مع الخادم (المنفذ 8001) و2FA — تحتاج مطابقة عقد الـ API (انظر آخر الملف).

## أ) الأبسط والأوفر للمساحة: بناء APK في السحابة (بلا Android Studio وبلا Gradle على جهازك)
1. أنشئ مستودعاً خاصاً على github.com، وارفع محتويات هذا المجلد كما هي (سحب وإفلات من المتصفح يكفي).
2. تبويب Actions ← "Build Android APK" ← Run workflow (ويعمل تلقائياً عند كل رفع).
3. بعد دقائق: افتح التشغيل الناجح ← Artifacts ← نزّل `lifevault-debug-apk` (ملف zip فيه app-debug.apk).
4. انقل الملف إلى الجوال وثبّته (اسمح بالتثبيت من مصدر غير معروف).
> سير العمل لم يُجرَّب على خوادم GitHub من جهتي؛ إن فشلت خطوة فأرسل لي سطر الخطأ من سجل Actions.

## ب) تشغيل الواجهة على الكمبيوتر (اختياري)
- ثبّت Node.js 22 LTS أو أحدث (Capacitor 8 وVitest 5 يتطلبان 22+). اختر مساراً على D: عند التثبيت.
- وجّه كاش npm إلى D: لتحمي C:  `npm config set cache D:\npm-cache`
- ثم داخل مجلد المشروع: `npm install` ثم `npm test` ثم `npm run dev`.

## ج) Android Studio محلياً (غير موصى به مع قرص C: الممتلئ)
يحتاج عشرات الجيجات (SDK وGradle). إن اضطررت: ثبّته وSDK على D:، وعيّن `GRADLE_USER_HOME` و`ANDROID_HOME` إلى D: قبل أول بناء.

## الاختبارات
`npm test` — 22 اختباراً: مطابقة PBKDF2 وHKDF مع Node (OpenSSL)، متجه اختبار معروف، كلمة مرور خاطئة، تلاعب بالنص المشفر، ربط AAD، الاستعادة، تغيير كلمة المرور، ولا نص صريح في التخزين.

## ما يلزم لإكمال المزامنة (يحتاج منك شيئين)
1. محتوى `http://127.0.0.1:8001/openapi.json` (أسماء المسارات وحقولها).
2. دالة اشتقاق المفاتيح الموجودة في dashboard.html، لأن الخزنة التي تُنشأ في المتصفح لن تفتح في التطبيق إلا إذا تطابقت ثوابت الاشتقاق (انظر رأس src/crypto/lv-crypto.ts).
