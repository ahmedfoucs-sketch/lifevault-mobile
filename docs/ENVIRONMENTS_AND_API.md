# LifeVault — API environments and mobile connectivity

## API configuration
`src/services/api-config.ts` is the single source of truth.

| Build | Configuration | Behaviour |
|---|---|---|
| Vite development | `.env.development` | Local FastAPI default: `http://127.0.0.1:8001/api/v1` |
| Production web | `VITE_API_BASE` | Required; HTTPS |
| Android / iOS | `VITE_API_BASE` at build time | Required; HTTPS; never falls back to device localhost |
| Explicit debug exception | `VITE_ALLOW_INSECURE=true` | Debug only; must not be enabled for release |

A production build without an API URL can still compile, but API requests stop with a clear configuration error. It will not silently call localhost.

## Why this matters
In a phone WebView, `127.0.0.1` means the phone itself, not the developer computer or remote backend. The former API client silently used that address whenever `VITE_API_BASE` was missing. This is now prevented for production builds.

## GitHub Actions
Create a repository Actions **Variable** named `LIFEVAULT_API_BASE` containing the real public HTTPS API base, including `/api/v1`. Do not put this public endpoint in a secret. Android workflows validate that it exists and is HTTPS before building, then pass it to Vite as `VITE_API_BASE`.

The repository does not define the production backend domain. No domain has been invented or inserted.

## Backend requirements — not verifiable in this repository
The backend must:
- Serve a valid HTTPS certificate.
- Allow the actual web origin and the Capacitor origins `https://localhost` (Android) and `capacitor://localhost` (iOS) through an explicit CORS allow-list.
- Allow the required methods and headers, including POST, OPTIONS, Content-Type and Authorization.
- Implement the auth, 2FA and sync routes consumed by `src/services/api-client.ts`.

The backend source is not present in this repository. Backend CORS, authentication, roles and data recovery therefore remain unverified.

## Mobile
Android is generated by the Android CI workflow when the `android/` directory is absent. Capacitor sync must succeed before Gradle builds. iOS requires macOS, Xcode, an Apple Developer account and signing/provisioning; it cannot be built in a Linux GitHub Actions runner without a separate macOS workflow.

## AI COMMAND CENTER
LifeVault remains an independent application and data boundary. The Command Center may link to its production URL, but must not share cookies, tokens, databases or vault contents.
